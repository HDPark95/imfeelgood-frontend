# 아임필굿 프론트엔드

영양제 최적 섭취 플랜 제공 서비스

## 프로젝트 개요

아임필굿은 여러 종류의 영양제를 복용하는 사용자에게 **언제, 어떻게 먹으면 가장 좋은지** 최적의 섭취 플랜을 제공하는 영양제 관리 앱입니다.

### 핵심 기능

- 영양제 간 상충 성분 자동 분석
- 최적 섭취 시간 자동 추천
- 시간대별 섭취 플랜 자동 생성
- 섭취 기록 및 알림
- 섭취 히스토리 통계

## 기술 스택

- **프레임워크**: React 18
- **빌드 도구**: Vite 5
- **라우팅**: React Router 6
- **스타일링**: Tailwind CSS 3
- **언어**: JavaScript (ES6+)

## 시작하기

### 설치

```bash
cd ~/workspace/imfeelgood-frontend
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

개발 서버가 http://localhost:5173 에서 실행됩니다.

## 주요 화면

1. **온보딩**: 서비스 소개 및 첫 영양제 등록
2. **홈**: 일일 섭취 플랜 확인 및 체크
3. **영양제 목록**: 등록된 모든 영양제 관리
4. **영양제 추가**: 바코드/검색/수동 입력
5. **섭취 기록**: 주간/월간 통계 확인
6. **설정**: 프로필 및 알림 설정
